# Project Rules & Customizations

This file outlines style guidelines, behavioral constraints, and motion design principles for the Impulse website.

## Motion Design Principles (Matt Jumper Guidance)

Practice restraint in web animations to avoid distracting the user. Ensure motion feels **crafted**, **intentional**, and **premium**, rather than aimless.

### 1. The Four Reasons to Use Motion
* **Engagement:** Create memorable experiences that elevate brand perception and trust.
* **Quality:** Smooth, intentional easing signals craftsmanship and professionalism.
* **Communication:** Explain complex structures or service capabilities clearer than static components.
* **Guidance:** Direct the user's attention to interactive elements (e.g., active tab states, buttons, links).

### 2. Core Principles
* **Purpose:** Every scroll trigger or page animation must have a clear functional role. If it can be removed without affecting the user experience, remove it.
* **Brand Expression:** Motion acts as the brand's body language. For Impulse (a professional corporate consulting firm), animations should feel **snappy and precise** (no bouncy or playful easing).
* **Cohesion:** Use consistent durations (`0.8s` to `1.2s`), timings, and easing functions (like `power3.out`) globally to make the site feel unified.

### 3. Mistakes to Avoid
* **Avoid animation fatigue:** Do not make every header, tag, and text element animate.
* **Avoid aimless scroll effects:** Scroll animations should feel like a natural consequence of user action, not a performance-slowing distraction.
* **No fake preloaders:** Avoid inserting preloaders unless they have critical functionality.
